# Último Scout

Plataforma web de scouting para centralizar, validar e facilitar a busca por atletas de futebol amador e universitário acima de 18 anos.

## Problema abordado

Atletas que saem das categorias de base (18–23 anos) perdem visibilidade institucional e dependem de envios informais por redes sociais e aplicativos de mensagem. Esse processo é desorganizado, difícil de verificar e pouco eficiente para recrutadores de clubes com orçamento limitado.

## Objetivos

- Centralizar o cadastro validado de equipes amadoras e universitárias.
- Oferecer uma vitrine técnica com ficha, atributos e vídeos (embeds).
- Permitir a busca de atletas por localização e posição.
- Reduzir o custo da primeira triagem para olheiros e clubes.

## Tecnologias previstas

- **Frontend:** HTML, CSS e JavaScript
- **Backend:** Node.js + Express
- **Banco de dados:** MySQL
- **Outros:** Chart.js (gráfico de radar), embeds de YouTube/Instagram/TikTok
- **Ferramentas:** Git, GitHub, Figma, Visual Paradigm, Postman, VS Code
